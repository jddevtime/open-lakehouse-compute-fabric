# MCP tools

The tools of the Model Context Protocol endpoint `POST /mcp` (see the [MCP guide](../guides/mcp.md) for connecting an agent). Every tool runs with the permissions of the person or token behind the connection and is listed only to callers who hold the permission it needs somewhere; tools that depend on a module are listed only while that module is installed. Read tools need the token scope `mcp`; tools marked *write* also need `mcp:write`. The Intelligence tools (`intel_*`, `governance_*`) only read: there is no MCP tool for the sample endpoint and none that changes the asset graph, a source, a scan or governance data (ADR 0014). Source: `src/olcf/mcp/tools.py`, `src/olcf/mcp/intel_tools.py`, `src/olcf/mcp/gov_tools.py`.
