# Permissions, roles and token scopes

Authorisation is enforced on the server for every call (`Principal.require`). A **role** is a bundle of permissions; a **binding** grants a role to a principal at a scope (organisation, workspace, item, connection, runtime or pool). A **token scope** can only narrow what the principal's roles allow. Source: `src/olcf/security/rbac.py`.

## Roles

| Role | Permissions | Platform-level |
|---|---|---|
| `PlatformAdmin` | all (`*`) | yes |

| `WorkspaceAdmin` | 38 | no |
| `Contributor` | 26 | no |
| `Operator` | 10 | no |
| `Viewer` | 9 | no |
| `ServicePrincipal` | 18 | no |

Platform-level roles may only be granted by a principal that itself holds every permission of the role (the *no-escalation rule*); workspace-level roles are granted by whoever holds `identity.manage` (organisation scope) or `workspace.members.manage` (workspace scope).
