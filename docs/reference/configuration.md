# Configuration reference

Configuration has three layers. Precedence, highest first:

1. **Environment variables** with the `OLCF_` prefix; `__` separates nesting (`OLCF_SERVER__PORT=9000`, `OLCF_DB__URL=postgresql+psycopg://...`).
2. **`<data_dir>/config.toml`** (a starter file is written by `olcf init`).
3. **Built-in defaults** listed below.

Beyond those *process settings* (read at start-up, a restart is needed to change them) there are **runtime settings** stored in the database and changed live with `olcf settings set` or `PUT /v1/admin/settings/{key}` (PlatformAdmin, permission `admin.settings`), and a few **special environment variables** read by specific components. All three are listed on this page.

An `OLCF_<SECTION>__<KEY>` variable overrides that one key; the other keys of the section in `config.toml` are kept.

The *Environment variable* column was verified mechanically: for each of the 69 process settings the generator set the variable, built `Settings()` and checked that the value arrived (including the nested `__` form).
