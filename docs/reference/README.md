# Reference

Exact names, flags, endpoints and defaults. Pages marked *generated* are produced from the code by scripts in `scripts/` and are checked for staleness by `scripts/check_docs.py`; regenerate them instead of editing them. The generators are listed in [development setup](../development/setup.md#generated-documentation).

| Page | Contents | Source |
|---|---|---|
| [CLI](cli.md) | every `olcf` command, option and exit code | generated by `scripts/gen_cli_docs.py` (a front end of `scripts/gen_reference.py --only cli`) |
| [REST API](api.md) | every endpoint with parameters, bodies and permissions; the machine-readable form is [`docs/api/openapi.json`](../api/openapi.json) and, on a running server, `/v1/openapi.json` and `/v1/docs` | generated by `scripts/gen_api_docs.py`, which also writes `docs/api/openapi.json` (the Markdown renderer is `scripts/gen_api_reference.py`) |
| [Python SDK](sdk.md) | the `olcf.sdk` client: resources, methods, exceptions | generated by `scripts/gen_sdk_docs.py` |
| [Fabric SDK](fabric-sdk.md) | the `olcf_fabric` package that runs inside a Fabric notebook | generated by `scripts/gen_sdk_docs.py` |
| [Configuration](configuration.md) | configuration file layout, every setting with its `OLCF_...` variable and default, the runtime settings registry, other environment variables | generated by `scripts/gen_reference.py` |
| [Permissions](permissions.md) | permissions, role matrix, token scopes | generated by `scripts/gen_reference.py` |
| [Errors](errors.md) | the error envelope, error codes, job failure categories, job states | generated by `scripts/gen_reference.py` |
| [Events](events.md) | event types and audit actions | generated by `scripts/gen_reference.py` |
| [MCP tools](mcp-tools.md) | every MCP tool: description, permission, token scope, arguments | generated by `scripts/gen_reference.py` |
| [Health checks](health-checks.md) | every health check and what it tests | generated by `scripts/gen_reference.py` |
| [Fabric rules](fabric-rules.md) | the 73 compatibility rules of the analyzer | generated by `scripts/gen_sdk_docs.py` |
| [Ports and networking](ports-and-networking.md) | listening ports, outbound connections, proxies, reverse proxy | written by hand, verified |
| [Lineage support](lineage-support.md) | what each Intelligence lineage analyzer and run-time emitter supports, partly supports and does not support, with the confidence of the edges it emits | written by hand, spot-checked against the analyzers |
| [Glossary](glossary.md) | the vocabulary | written by hand |
| [FAQ](faq.md) | short answers with links | written by hand |

Machine-readable schemas are in `schemas/` (execution capsule `capsule-v1.json`, pipeline document `pipeline-v1.json`, Fabric import support, sample data) and served by the API (`GET /v1/pipelines/schema`, the capsule schema through the Fabric integration).

How the reference relates to the other documentation: [concepts](../concepts/README.md) explain, [guides](../guides/README.md) show how, [operations](../operations/README.md) cover running it.
