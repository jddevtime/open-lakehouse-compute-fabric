`from olcf.sdk import Client` (synchronous) or `AsyncClient` (same surface, awaitable). Methods return plain `dict`/`list` values decoded from the REST API; list methods return a `Page` (a `list` with `.next_cursor`). The REST call behind each method is shown so the SDK can be read next to [the API reference](api.md). Anything without a wrapper is reachable with `client.request(method, path)`.

Guide: [Using the SDK](../guides/sdk.md).

## Client

- `Client.from_env(**kw: Any)` - `OLCF_URL` / `OLCF_TOKEN` (+ CA variables) from the environment.
- `Client.from_context(name: str | None = None, **kw: Any)` - Use the credentials stored by `olcf login` (the current context, or `name`). Refreshed tokens are written back.
- `Client.login(username: str, password: str)` - Username/password login; stores the access and refresh tokens on the client (and returns the full answer).
- `Client.logout()` - Revoke the session on the server (refresh token and access tokens) and forget the tokens locally.
- `Client.me()`
- `Client.health()`
- `Client.info()`
- `Client.request(method: str, path: str, **kw: Any)` - Escape hatch for endpoints without a wrapper: `client.request("GET", "/jobs/stats")` (`path` is relative to `/v1`).
- `Client.paginate(fn: Callable[..., Any], *args: Any, **kw: Any)` - Iterate every item of a list method: `for j in client.paginate(client.jobs.list, state="failed")`.
- `Client.set_token(token: str | None, refresh_token: str | None = None)`
- `Client.close()`

## Errors

All SDK errors derive from `OlcfSdkError`; HTTP errors derive from `ApiError` and carry `status`, `code`, `message`, `remediation` and `correlation_id`.

| Exception | Base | Raised for |
|---|---|---|
| `ApiError` | `OlcfSdkError` | A non-2xx answer from the REST API. |
| `AuthenticationError` | `ApiError` | HTTP 401: missing, expired or invalid credentials. |
| `BadRequestError` | `ApiError` | HTTP 400. |
| `ConflictError` | `ApiError` | HTTP 409 (duplicate name, invalid state transition, idempotency key reuse...). |
| `JobFailedError` | `OlcfSdkError` | Raised by `jobs.wait(..., raise_on_failure=True)` when the job ended in a state other than `succeeded`. |
| `NotFoundError` | `ApiError` | HTTP 404. |
| `OlcfConnectionError` | `OlcfSdkError` | The control plane could not be reached (DNS, TCP, TLS, proxy, timeout) after the configured retries. |
| `OlcfSdkError` | `Exception` | Base class of everything the SDK raises on purpose. |
| `OlcfTimeoutError` | `OlcfSdkError` | A `wait` helper ran out of time (the server-side work may still be running). |
| `PermissionDeniedError` | `ApiError` | HTTP 403: authenticated but not authorised (RBAC, token scope or policy). |
| `PreconditionFailedError` | `ApiError` | HTTP 412: the `If-Match` ETag no longer matches; re-read the resource and retry. |
| `RateLimitError` | `ApiError` | HTTP 429. |
| `ServerError` | `ApiError` | HTTP 5xx. |
| `UnavailableError` | `ServerError` | HTTP 503: a service is not available in this deployment (or is starting). |
| `UnsupportedError` | `ValidationError` | HTTP 422 with code `unsupported` / `compatibility_blocked`: fail-closed, the platform refuses to guess. |
| `ValidationError` | `ApiError` | HTTP 422: the request is well-formed JSON but semantically invalid. |
